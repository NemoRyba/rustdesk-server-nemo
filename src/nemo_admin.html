Directory users — select who may use TBFDesk

Search your Windows domain and tick the users allowed to sign in to TBFDesk. Enabling a user adds them to the ACL tab, where you set which computers they may reach and their per-user policy. Only enabled users can log in (with Require login on). Search by name, username, email, or category — job title, department, or group (e.g. type techniker to list everyone in that role). Wildcards work (tech*), and multiple words narrow the results (all must match). Disabled, system, and machine accounts are hidden. Browsing the directory needs a read-only service account — set a Bind DN + password in the LDAP settings above and Save first.

Admin policy

Applies to every user marked Admin in the table above. Admins bypass all normal policies (named, default and per-user) and get this one instead. It is full access by default — change any control to Deny to restrict what admins may do.
